KLYX — PAIEMENT CLAIR ET NOTIFICATIONS
======================================

Cette version conserve le verrou anti-double paiement et ajoute :

- un seul bouton « Payer la réservation » avant confirmation ;
- aucun bouton de paiement après confirmation ;
- « Paiement effectué avec succès » pour le client ;
- « Paiement reçu avec succès » pour le prestataire ;
- un motif clair pour le client si la banque refuse le paiement ;
- aucune fausse notification de paiement reçu pour le prestataire ;
- la vraie cloche de notifications reliée au profil KLYX actif.

1. COPIER LES FICHIERS
----------------------

Extrais le ZIP, puis copie uniquement son contenu dans :

C:\Users\fenjo\Documents\klyx

Choisis « Remplacer les fichiers dans la destination ».
Conserve ton fichier .env.local.

2. SUPABASE
-----------

Dans Supabase > SQL Editor > New query, ouvre et exécute uniquement :

Le résultat attendu est : Success.

Ne relance aucun ancien fichier SQL.

3. STRIPE WEBHOOK
-----------------

Dans le webhook Stripe déjà utilisé par KLYX, vérifie que cet événement est
activé :

payment_intent.payment_failed

Les événements de succès déjà utilisés restent :

checkout.session.completed
checkout.session.async_payment_succeeded
checkout.session.async_payment_failed

4. VÉRIFIER LE BUILD
--------------------

Dans PowerShell :

cd C:\Users\fenjo\Documents\klyx
Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue

Résultat attendu : 47/47 pages générées.

Ne lance pas npm audit fix --force.
